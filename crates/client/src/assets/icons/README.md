# アイコン差し替え用フォルダ

ここに画像ファイルを置くと、同名の組み込み SVG アイコンを **画像で上書き** できます。
コードを触る必要はありません(ビルド/HMR で自動反映)。

## 使い方

`<アイコン名>.<拡張子>` で保存するだけ。対応拡張子: `png` / `jpg` / `jpeg` / `webp` / `svg` / `gif`。

例:
- `hosts.png`    → サイドバーの Hosts アイコンを置き換え
- `settings.svg` → Settings アイコンを置き換え
- `close.png`    → ウィンドウの閉じるボタンを置き換え

## アイコン名 (= ファイル名)

`src/icons.ts` の `IconName` と一致させること:

| 名前 | 用途 |
|------|------|
| `hosts` | サイドバー: Hosts |
| `settings` | サイドバー: Settings |
| `add` | ホスト追加 (＋) |
| `refresh` | 再読み込み |
| `edit` | カードの編集 |
| `delete` | カードの削除 |
| `chevron` | カード右端の矢印 |
| `minimize` | ウィンドウ最小化 |
| `maximize` | ウィンドウ最大化 |
| `close` | ウィンドウ閉じる |

## 注意

- 表示サイズは各所の `font-size` 基準 (1em)。元画像は正方形・余白少なめが収まりやすい。
- png/jpg はそのままの色で表示される (テーマのアクセント色には追従しない)。色を
  テーマに追従させたい場合は組み込み SVG または currentColor を使う単色 SVG を推奨。
- ファイルを消せば組み込み SVG に戻る。
