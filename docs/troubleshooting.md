# トラブルシュート

症状から確認点を引くための早見表です。無人起動 (自動起動・WoL) 特有の項目は
[remote-access-setup.md](remote-access-setup.md) の末尾にも詳しい表があります。

## 接続まわり

| 症状 | 確認点 |
|------|------|
| 接続できない | `tailscale status` で双方がオンラインか。client の接続先 `<port>` が host の `--port` と一致しているか |
| host に届かない (Tailnet 経由) | host が Tailscale IP に bind しているか。Tailscale 未導入だと `0.0.0.0` にフォールバックする。意図的に LAN 公開するなら `--bind 0.0.0.0` |
| パスワードが通らない | client の入力値が host の保存値と一致しているか。`--set-password` をタスクと**同じユーザー**で (昇格せず) 実行したか。`%LOCALAPPDATA%\Aurora\password.bin` があるか |
| ハンドシェイクで切れる | パスワード (PSK) 不一致が最有力。各ステップ 10 秒でタイムアウトするため、無応答だと切断される |
| 2 台目から接続できない | host は同時に 1 接続のみ受理する。先のセッションを切ってから接続する |

## 映像/音声

| 症状 | 確認点 |
|------|------|
| 接続はできるが映像が来ない | ログオンセッションがアクティブか (ロック画面のみでは DXGI が止まる構成あり)。GPU ドライバ。host ログ (`%LOCALAPPDATA%\Aurora\host.log`) を確認 |
| カクつく / 遅延が増える | 高リフレッシュレートモニタでデコードが溢れている可能性。`--fps` で送出上限を下げる。帯域が細いなら `--max-bitrate` を下げる |
| 画面が乱れて戻らない | パケットロスでキーフレーム待ち。ツールバーから再要求するか、一時的なら次のキーフレームで回復する |
| 映像が眩しい/白飛びする | HDR 有効ディスプレイの既知制約 (SDR トーンマップ)。ディスプレイの HDR を切ると回避できる |
| 音が出ない | host 起動時に音声ループバックの初期化に失敗すると映像のみで継続する (ログに `audio capture disabled`)。再生デバイスを確認 |

## 自動起動 / 無人運用

| 症状 | 確認点 |
|------|------|
| `--install` が失敗する | 管理者権限で実行しているか (`/RL HIGHEST` 登録のため) |
| タスクは動くが映像が来ない | ログオンセッションがアクティブか。Windows サービスではなく「ログオン時タスク」が必要 (DXGI は Session 0 で動かない) |
| WoL で起きない | 中継役と自宅 PC が同一サブネットか。MAC が正しいか。高速スタートアップを無効化したか (`powercfg /h off`)。S5 不可なら S3/S4 (スリープ/休止) で運用 |
| 自動ログオンしたい | 無人運用で「ログオン時」を満たすには自動ログオン設定が要る (セキュリティと要相談) |

## パスワード変更ができない

| 症状 | 確認点 |
|------|------|
| `--set-password` / `--clear-password` が拒否される | クライアント接続中は変更できない (締め出し防止)。切断してから実行する |
| 「current password does not match」 | 既存パスワードがある場合は現在のパスワード照合が要る。トレイの「パスワード変更」からも同様 |

## インストール時の警告

| 症状 | 確認点 |
|------|------|
| SmartScreen / Defender が警告する | 配布インストーラは未署名。リモート操作 + 入力注入 + 画面キャプチャという性質上、誤検知もあり得る。配布元を信頼できる場合のみ続行する |

## ログの見方

ホストのログは既定で `aurora=info`。詳細を見たいときは:

```powershell
# 端末起動 (debug ビルド) なら環境変数で
$env:RUST_LOG = "aurora=debug"; cargo run -p aurora-host

# トレイ常駐 (リリース) は引数でファイルログのレベルを上げる
.\aurora-host.exe --log-level debug
# 出力先: %LOCALAPPDATA%\Aurora\host.log
```
